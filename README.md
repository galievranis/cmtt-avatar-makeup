# CMTT Avatar Makeup

Статический макет vc.ru с анимированными рамками аватарок.

- `index.html` — главная.
- `post.html` — статья и 12 комментариев (9 демонстрационных).
- `blog.html` — блог автора и два поста.
- `avatars.js`, `avatars.css` — случайный выбор и наложение рамок.
- `frames/` — девять WebP-рамок.

В блоге аватарка 90 × 90 px, рамка 98 × 98 px. На остальных аватарках рамки больше на 4 px по ширине и высоте. При обновлении страницы рамки меняются.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при каждом push в `main`. В Settings → Pages источником должен быть **GitHub Actions**. Сборка и установка зависимостей не требуются.

## Локальный просмотр

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Материалы

Учебный демонстрационный макет. Верстка и контент взяты из предоставленных сохранённых страниц vc.ru, рамки — из предоставленных файлов и ссылки Civitai. Права на сторонние материалы принадлежат их авторам; лицензия на их повторное использование этим репозиторием не предоставляется.

## Дизайн-система и проверки

Правила фронтенда находятся в `.agents/skills/osnova-design-system/SKILL.md`. `design-system.css` содержит токены из скилла, `prototype.css` — корректировки адаптивности, `prototype.js` — локальные состояния подписки, закладок, вкладок и меню. Сохранённый HTML остаётся основой верстки.

```sh
python3 scripts/check-site.py
node --check avatars.js
node --check prototype.js
```

Проверены три страницы на 390, 639, 640, 924, 925, 1239, 1240 и 1440 px. Макет использует локальные демонстрационные данные; кнопки подписки и закладок сохраняют состояние только в браузере.
